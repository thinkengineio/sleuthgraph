# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| v0.1.x  | Yes (current) |

## Reporting a Vulnerability

**Do NOT open public GitHub issues for security vulnerabilities.**

If you discover a security vulnerability, please report it responsibly:

- **Email:** security@sleuthgraph.io
- **GitHub:** Use [GitHub's private vulnerability reporting](https://github.com/francose/sleuthgraph/security/advisories/new)

### What to expect

- **48 hours** — We will acknowledge receipt of your report.
- **7 days** — We will provide an initial assessment and next steps.

Please include as much detail as possible: affected component, steps to
reproduce, impact assessment, and any suggested fix. We appreciate
coordinated disclosure and will credit reporters (unless you prefer to
remain anonymous) once a fix is released.
